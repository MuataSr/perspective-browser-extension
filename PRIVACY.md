# Privacy Policy for Perspective Chrome Extension

**Effective Date: January 25, 2026 · Last updated: October 6, 2026**

## 1. Data Collection

Perspective does not collect, store, or share any personal data. All AI analysis runs locally on your device.

## 2. Network Use

The only network activity is a one-time download of the AI model files (the model itself and its runtime) from Hugging Face and GitHub. Article text is never sent to any server — there is no backend, no API key, and no account. After the model has downloaded, Perspective works fully offline.

## 3. Local Storage

Perspective uses Chrome's storage API to save:
- Extension settings (model choice, theme preferences, feature toggles)
- Cached analysis results (stored locally for 7 days)
- Downloaded on-device model files (cached by the browser; cleared by removing the extension)

## 4. No Tracking

We do not use any analytics, tracking, or third-party services that collect user data.

## 5. Your Rights

You can clear all data at any time by:
- Removing the extension from Chrome
- Clearing Chrome storage for the extension

## 6. Contact

For questions about this privacy policy, please open an issue at:
